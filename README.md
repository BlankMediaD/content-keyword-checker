# Content Keyword Checker

This small web page lets you check if given keywords appear in a block of content. Matches are highlighted and the results can be saved for later.

## Usage

1. Open `public/index.html` in your browser.
2. Enter a title, keywords (comma or newline separated) and the content. Click **Check & Save** to view and store the results.
3. Previous checks are listed below the form. Click an item to load it again.
4. Use **Export History** to download a `data.json` file with your saved checks, or **Import History** to load a previously saved file.

All data is kept in your browser using localStorage, so no server is required.
