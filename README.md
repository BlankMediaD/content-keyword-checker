# Content Keyword Checker

This is a small web tool to check if certain keywords appear in a block of content. Results are stored in your browser and can be exported to a JSON file.

## Usage

1. Open `public/index.html` in any modern browser.
2. Enter a title, a list of keywords (comma or newline separated) and the content. Click **Check & Save** to see results and store them locally.
3. Use **Download History** to save your results as a `data.json` file. You can also load a previously saved file using the import field.
4. Previous checks are listed at the bottom. Click an entry to load it again.

All data is kept in your browser's local storage.
